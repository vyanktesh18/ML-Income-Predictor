# 💰 Income Classifier – Machine Learning Web Application

A Machine Learning based web application that predicts whether a person's annual income is **above or below ₹40,00,000 per year** based on demographic, educational, employment, and financial information.

The project uses a **Random Forest Classifier** along with **Recursive Feature Elimination (RFE)** for feature selection. A Flask web application provides an interactive interface where users can enter their details and receive an income prediction with confidence.

---

## 📌 Project Overview

The objective of this project is to build a machine learning classification system that can analyze a person's information and predict their income category.

The project includes:

- Data preprocessing
- Categorical data encoding
- Feature scaling
- Random Forest classification
- Feature selection using RFE
- Model evaluation
- 5-fold cross-validation
- F1-score evaluation
- ROC-AUC evaluation
- Accuracy evaluation
- Flask web application
- Interactive prediction form
- Prediction confidence
- Model performance comparison

---

## 🎯 Problem Statement

Income classification is a common Machine Learning classification problem where a person's demographic and employment-related information is used to predict their income category.

This project uses the Adult Income dataset and develops a Random Forest based classification model to classify income into two categories:

- `> Rs 40,00,000 / year`
- `<= Rs 40,00,000 / year`
